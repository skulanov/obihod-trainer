# Папка аудиозаписей (`public/audio`)

Помещайте сюда MP3-файлы строго в формате:

```text
<category>_<glas>_<knee>.mp3
```

- `category`: `trop` (тропари) или `stih` (стихиры)
- `glas`: цифра от `1` до `8`
- `knee`: `1`, `1a`, `2`, `2a`, `3`, `4`, `5` или `К`

Примеры: `trop_1_1a.mp3`, `trop_8_К.mp3`, `stih_4_5.mp3`.

Перед публикацией на GitHub Pages убедитесь, что права на публичное распространение всех размещённых в этой папке аудиозаписей подтверждены.
